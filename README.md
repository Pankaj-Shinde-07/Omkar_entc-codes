# Omkar ENTC Codes

Microcontroller and VLSI lab examples, with a searchable browser for reading the source files.

## Collections

- `micro_keil/` — 8051 and microcontroller C examples, plus interrupt notes.
- `vlsi/` — Verilog designs and testbenches.

## GitHub Pages

The site is a static HTML/CSS/JavaScript page at the repository root. It loads source files directly from the repository and does not require a build step. The workflow in `.github/workflows/deploy-pages.yml` deploys it when `main` changes. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** once to enable the first deployment.
